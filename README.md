# Craft Frontend PPT

为网页前端建立贴合任务简报的视觉方向，并进行生产级构建、改进、审查、动效与配乐设计。适用于落地页、作品集、品牌与活动页面、在浏览器运行的网页演讲 / Web PPT、视觉文章、滚动叙事和动态解释图解等创作型构建。

> 本仓库是一个标准 `SKILL.md`，供支持 SKILL.md 的 Agent 平台加载使用。

## 安装

本 skill 兼容 Claude Code / Codex / 其他支持 `SKILL.md` 的平台：

- 将本仓库整体放入对应平台的 skills 目录（如 `~/.workbuddy/skills/craft-frontend-ppt/`、`~/.claude/skills/craft-frontend-ppt/` 等）；
- 或按各平台的 skill 安装方式引入本目录。

首次使用前，建议先阅读 `SKILL.md` 顶部的「判断任务路线 / 交付类型」，按 Build / Improve / Review 选择路线。
