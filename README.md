# Craft Frontend PPT

让网页成为舞台，让视觉、动效与声音替你的内容开口。这个 skill 从内容和使用场景出发，确定视觉方向，再把版式、交互、动效和配乐做进前端。可以从零做网站和浏览器里的演讲，也可以接着已有页面改，把值得强调的内容做出分量。

## 可以做些什么

- **落地页、作品集和活动页面**：“帮我做一个作品集，让人一进来就知道我擅长什么。”从作品怎么选、页面怎么读开始，做出贴合内容的视觉和浏览节奏。
- **网页演讲 / Web PPT**：“把这份内容做成在浏览器里讲的演示。”用页面切换、动效和配乐组织讲述，让观众跟得上重点。
- **视觉文章和滚动叙事**：“把这个故事做成一边滚动、一边展开的网页。”让文字、画面和运动共同推进内容，读者往下看时能感到变化。
- **动态解释图解**：“这个过程光用文字讲不清，帮我做个能动、能操作的图解。”让读者通过观察和交互理解关系。
- **改进已有界面**：“这个仪表盘能用了，帮我调整布局和样式，再看看交互顺不顺。”沿用现有技术栈和设计基础，补上影响使用和观感的细节。
