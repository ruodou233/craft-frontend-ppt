# 动效工程

只有动效能实质支持任务时才使用本参考。

## 判断动效是否有帮助

考虑用户遇到该交互的频率。高频操作优先直接迅速；更具表现力的序列留给低频、解释性或定义身份的时刻。

让每段动画都有明确用途：

- 保持空间连续性；
- 解释状态或关系；
- 确认操作；
- 缓和有意义的变化；
- 展示功能；
- 以 Brand（品牌表达）为主时营造氛围。

用途不充分时，让布局、色彩和字体承担表达。

## 设计行为

- 让频率与幅度匹配事件的重要性。
- 多个元素共同描述同一时刻时使用协调序列；重复使用的控件采用局部反馈。
- 按运动类型选择缓动：进入与反馈使用灵敏减速，屏幕内移动使用平衡加减速，恒速运动使用线性进度。
- 把变换原点设在交互来源，例如弹出层触发器；没有锚点的对话框保持居中。
- 让手势和可逆交互可被中断，并能从当前状态自然继续。
- 增强前就让内容可用；动效应丰富一个本来已可理解的界面。

## 高效实现

常规动效优先使用 `transform` 和 `opacity`。只有裁切、滤镜、遮罩、布局动画或弹簧的视觉或物理特性不可替代，且实测性能可接受时才使用。明确指定动画属性，不使用宽泛的过渡声明。

项目已有动效库，或手势、共享布局、编排与中断行为值得引入时使用该库。简单的悬停、焦点和状态过渡留在 CSS 中。

连续动画离屏或文档隐藏时停止调度与绘制，恢复时避免时间大幅跳变。画面稳定后不要继续维持全局逐帧循环。

滚动进度更新时避免逐帧读取布局；把活动图层、拆分文本节点、Canvas 分辨率和帧序列数量控制在实测性能预算内。

## 编排滚动驱动的视觉与动态排版

滚动可能只决定启动时机，也可能连续控制场景进度，因此先选择时间关系：

- `scroll-triggered`：元素进入指定范围后播放一个独立序列，适合一次性揭示、标题入场和简短转场。
- `scroll-linked` / `scrubbed`：把滚动进度映射到场景状态，适合可逆的空间变化、遮挡、缩放、帧序列、逐字符强调和多层视差。

为进度绑定场景设计完整首帧、稳定中间态和明确末帧，使停止、反向滚动和快速跳转仍然连贯。布局、字体和媒体稳定后按当前滚动位置初始化进度，并在尺寸变化、字体重排、历史恢复或直接跳转后重新计算。使用确定性的场景进度，使 `0%`、`25%`、`50%`、`75%`、`100%` 状态可重复捕获。

### 滚动绑定的多层视差

只有视觉作品确实需要用深度表达空间、注意力或叙事关系时，才采用滚动绑定的多层视差（scroll-scrubbed multi-plane parallax）；它只是滚动动效的一种分支。为前景、主体、中景和背景指定语义职责，让滚动产生揭示、接近、分离、遮挡或转化，不做无意义的不同速漂移。

### 滚动驱动的动态排版

文字本身需要承担视觉事件时，可先用拆分文字（split text）把完整文本按行、词、字符或其组合建立可动画节点，再选择揭示、高亮、位移、缩放或显隐等动态排版行为。逐字符错峰动画（per-character stagger animation）描述的是字符之间的时间或进度偏移：它既可由 `scroll-triggered` 独立时间线触发，也可由 `scroll-linked` / `scrubbed` 进度驱动，还可用于悬停或场景切换；不要把拆分单位、错峰方式和触发关系混为一类效果。

让辅助技术读取连贯原文，把纯装饰拆分节点或副本隐藏于无障碍树；首次渲染、减少动态效果和动画未初始化时仍显示完整文字。字体或宽度变化后重新拆分，并清理旧包装节点、时间线和触发器。`run-live` 视觉在离屏或文档隐藏时暂停，恢复时避免时间轴突然跳变。

## 提供减少动态效果体验

尊重用户的动态效果偏好。通过即时切换、克制淡入淡出或静态构图保留信息与状态变化；减少动态效果时移除氛围运动、视差和装饰性位移。

## 验证

相关时测试首次进入、直接 URL 锚点、历史恢复、停止、反向、快速跳转、尺寸变化、字体加载、隐藏标签页恢复、窄屏、减少动态效果和低性能设备。确认文字始终可读，动效不会阻塞输入，场景不会停留在错误或不可见状态。
