# 改稿不破坏动画

讲稿一改再改是常态：换场合、删页、调顺序、换图。网页演讲里页面、特效、音乐互相靠页名和文字咬合，随手一改就可能让动画哑掉、音乐切错页，而且只在现场翻到那页才发现。下面这些规则来自几次真实交付的返工。

## 版本：复制上一个包再改，原包不动

每次新场合都新建一个带日期的文件夹，把上一个包整个复制过去，在新包里改。理由：上一次讲过、验证过的版本是唯一确定能用的东西；改坏了随时能对照，也能直接回退去讲。交给别人（或另一个 Agent）接手时，写明「以哪个包为底、哪些旧文档已被取代不用读」。

## `data-label` 是接口

特效按页名认页（`match: label => label === '概率'`），背景音乐按页名锚点切曲，章节条按页名找起点，路线按页名过滤。所以：

- **改页名 = 改接口。** 要改名时先全局搜这个名字：`fx/*.js`、BGM 切换脚本、`#talk-route` 的 `chapters` 和 `routes`。一起改，或者干脆不改。
- 调页序不影响这些咬合（都按名字找，不按序号），这是页名做接口的好处。
- 新插页起一个新名字，不要和现有页重名。

## 动画要用到的字不能删

很多特效直接读页面上的文字和数字：数字滚动读 `data-roll-target`，荧光笔找「这几个字」，拆字处理 `h1/h2.anim-rise`，盖章读章节号。删减说明文字时，**先查对应的特效脚本**用到了哪些元素和字，再动手。只删标题下面的说明句、保留标题原文，通常是最安全的删法。

## 视频页约定

视频页给 `section` 加 `data-fx-focus="video"`：进页从头播放、背景音乐静音，翻走就停。章节条在视频页自动隐藏。视频文件放进包里用相对路径，文件还没到时页面上写明「视频待放入」，不要留一个黑框。演讲者窗的预览里视频换成 `poster` 图，所以给 `<video>` 配一张 poster。

## 逐页截图验证

改完不能只看代码 diff。用浏览器把每一页都走一遍：

1. `document.querySelector('talk-stage').goTo(i)` 跳到第 i 页（从 0 起），等 2–3 秒让入场动画和拆字播完再截图；节拍页要按 → 把拍点全亮再截一张。
2. 带音乐的稿子：从几个音乐边界页冷开（`#N` 深链接），确认响的是对的曲子；按 `M` 静音再恢复。
3. 视频页：进页会播、翻走会停、背景音乐恢复。
4. 打开减少动效再走一遍，每页都是完整的静态画面。
5. 打印预览（存 PDF）看一遍：跳过页不在里面、节拍都是亮的。

截图用缩小比例省 token，看具体样式用元素检查。验证时自己起的预览服务和浏览器标签，收尾关掉。

## 改动先给方案

动用户的讲稿页面前，先给「为什么改 / 改前 / 改后」，确认后再做；只改点名的地方和明显的事实错误。要大改就另起新包，旧包不动。

## 交付时附上的东西

- 打开方式：双击 `index.html` 或用本地静态服务器（音乐联动在 `file://` 下受浏览器限制，见 `soundtrack.md`）。
- 按键表：→ / ← / Home / End / P / F / Esc / T / M。
- 哪些页是跳过页、哪些路线可用（`?route=…`）。
- 讲稿和备注的对应关系：`#speaker-notes` 按页序对齐，含跳过页。
